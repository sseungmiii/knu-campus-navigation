기준 문서: 사용자가 제공한 `1인분_예선신청서.docx`의 서비스 기획서. 확인일: 2026-10-05. 아래는 사이트 개발 요구사항이며, 참가자 인적사항과 제출·서명 절차는 포함하지 않는다.

## 서비스 정의

크누패스(KNU-Pass)는 경북대생의 시간표와 목적지 강의실을 기준으로 집에서 강의실까지의 출발 시각을 계산하고, 캠퍼스의 지름길과 이동 동선 주변 생활 정보를 안내하는 웹 서비스다. 초기 대상은 복현캠퍼스의 핵심 건물과 통로이며, 특히 신입생이 재학생의 경험 정보를 활용할 수 있도록 돕는다.

신청서의 핵심 기능과 현재 시제품을 다음과 같이 구분한다. 이 문서는 개발 기준을 준비한 것이며, 아래 미구현 기능이 배포 사이트에 이미 구현됐다는 의미는 아니다.

## 기본 사용자 흐름

1. 시간표에 요일, 시작 시각, 건물, 강의실을 입력해 저장한다.
2. 한국 시간 기준 오늘 첫 수업을 표시한다. 사용자는 다른 수업이나 목적지도 선택할 수 있다.
3. 출발지와 이동 조건을 선택하고, 사용 가능한 경로 후보를 비교한다.
4. 선택 경로와 교통·층 이동 소요시간을 합산해 출발 시각을 표시한다.
5. 이동 경로와 단계 안내, 경로 주변 POI, 당일 식단을 확인한다.
6. 위치 권한을 허용한 경우 실제 이동 진행률과 권장 페이스를 비교한다. 권한이 없으면 명확히 표시한 시연 모드로 사용할 수 있다.

## 데이터 구조 초안

- 시간표 항목: id, 요일, 시작·종료 시각, 건물 id, 강의실, 층
- 캠퍼스 노드: id, 위경도, 건물·문·층, 유형, 출처, 현장 검증일
- 연결 링크: from, to, 이동 시간·거리, 계단·경사·엘리베이터, 통과 가능 시간, 양방향 여부
- POI: id, 유형, 위경도, 운영시간, 외부 데이터 연결 id
- 이동 계획: 수업 id, 도착 목표 시각, 출발지, 선택 경로, 구간별 시간, 경유·대기시간, 계산한 출발 시각

강의실과 엘리베이터·계단은 건물 좌표 하나로 합치지 않는다. 층 이동과 출입구 연결을 별도로 표현해야 신청서의 세부 안내를 구현할 수 있다. 필드명은 구현 시 조정할 수 있다.

## 계산과 표시 기준

- 출발 시각 = 수업 시작 시각 - 교통 시간 - 캠퍼스 이동 시간 - 층 이동 시간 - 선택한 경유·대기시간
- 자정 이전으로 역산되면 전날 출발임을 표시한다.
- 실제 교통·운영시간 API가 연결되지 않은 값은 예상 또는 사용자 입력으로 표시한다. 시연 값을 실시간 값으로 표시하지 않는다.
- 수업이 없는 날에는 출발 데드라인을 만들지 않는다. 이미 끝난 수업의 선택 규칙과 첫 수업·다음 수업 전환은 구현 시 명시한다.
- 폐쇄된 문이나 운영시간 밖의 건물 관통 동선은 후보에서 제외한다. 체력 온존 경로가 존재하지 않으면 없음을 표시한다.
- POI는 경로 선분에서의 거리로 30~50m 범위를 판단한다. 출발점과의 거리만으로 필터링하지 않는다.
- 메뉴가 없는 식당도 식당 카드와 운영정보를 유지하고 식단 미등록 상태를 표시한다. 메뉴 날짜와 실제 갱신 시각을 구분한다.
- GPS 오차·권한 거부·네트워크 실패 시에도 시간표와 경로 정보를 읽을 수 있어야 한다.

## AI 기능의 범위

신청서는 AI 챗봇을 시도 및 확장 기능으로 규정한다. LLM은 자연어에서 목적·경유지·조건을 구조화하고 대화형 안내를 담당한다. 장소 조회와 시간·경로 계산은 검증 가능한 코드 또는 백엔드 도구가 담당한다. LLM이 계산 결과나 장소를 임의로 만들어내지 않도록 한다.

API 키가 필요한 LLM과 교통 연동은 별도 백엔드가 필요하다. GitHub Pages는 정적 프론트엔드 배포에 사용하며, 브라우저 코드에 비밀키를 넣지 않는다.

## 기술 선택에서 남은 결정

신청서의 개발 활용 예에는 Kakao Map API가 적혀 있고 현재 앱은 Leaflet을 사용한다. 신청서의 기능을 구현하는 데 필요한 지도·경로·교통 API 지원과 비용을 비교한 후 전환 여부를 결정한다. 이번 배포에서 지도 엔진은 변경하지 않는다.

경계와 지름길 좌표의 공식성·정확성, 문 운영시간, 교통 데이터 공급자, 실내 GPS 한계는 별도 검증이 필요하다. 현재 좌표와 시간은 서비스 정확성을 입증하는 근거로 사용하지 않는다.
