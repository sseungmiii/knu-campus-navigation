# 다음 패치 반영 요청

기록일: 2026-10-27 (한국 시각)

상태: **2026-10-27: 1~9번 및 7-1번 구현·테스트·Vercel 배포 완료.** 아래 원래 요구사항을 기준으로 반영했다. 운영 주소: https://knu-campus-navigation.vercel.app/ · 실제 로그인 시간표에서도 09–18시 전체 표시를 확인했다.

## 1. 동일 과목의 공통 정보 즉시 반영

- 한 수업에 여러 요일·시간 회차가 있을 때, 한 회차에 정보를 입력하면 다른 회차에도 바로 반영한다.
- 수업명, 교수명, 강의 건물·강의실 등 시간 외 정보를 공통으로 처리한다.
- 요일·시작·종료 시각은 회차별로 유지한다.
- 등록·사진 인식 검토·수정 화면 모두에서 같은 원칙을 적용한다.
- 조정안: 기본은 공통 정보 즉시 반영으로 하되, 실제로 회차마다 건물·강의실이 다른 경우에는 해당 회차만 개별 설정할 수 있게 한다. 이미 개별 설정한 값을 공통 정보 수정으로 조용히 덮어쓰지 않는다.

## 2. 시간표 블록의 세로 비율 축소

- 현재 한 시간당 세로 길이가 길어 주간 시간표를 한눈에 보기 어렵다.
- 요일 한 칸의 가로 폭을 기준으로 **1시간 30분 블록이 대략 정사각형**이 되도록 비율을 조절한다.
- 아래 3번의 기본 시간 범위 전체 표시 요구도 함께 만족하도록 화면 크기에 맞춘다.
- 비율은 고정값이 아닌 목표값으로 둔다. 화면 크기상 두 조건을 동시에 만족할 수 없으면 **09:00–18:00 전체 표시와 글자 가독성**을 정사각형 비율보다 우선한다.

## 3. 기본 09:00–18:00 범위 한눈에 표시

- 시간표의 기본 표시 범위를 **09:00부터 18:00까지**로 둔다.
- 해당 범위의 월~금 시간표는 내부 세로 스크롤 없이 한눈에 들어오게 조절한다.
- 작은 화면에서도 시간 눈금·수업 블록·요일 구분이 읽히도록 한다.
- 블록에는 과목명·강의실 위주로 표시하고 교수명·상세 정보·관리는 별도 영역에서 확인한다. 상세 카드가 시간표 높이를 밀어내지 않게 한다.
- 09:00 이전·18:00 이후 수업은 숨기거나 삭제하지 않고, 범위 밖 수업이 있다는 표시와 확장 보기를 제공한다.

## 4. 입력창 자동 확대와 가로 넘침 제거

- 시간표 탭에서 텍스트 입력창을 눌렀을 때 화면이 자동 확대되지 않도록 수정한다.
- 불필요한 확대 동작을 제거한다.
- 좌우 드래그 시 화면이 밀리며 양옆 빈 공간이 드러나는 현상을 제거한다.
- 화면과 모든 입력 요소가 기기 가로 폭에 맞게 유지되도록 한다.
- 구현 시 입력창 자동 확대 문제를 해결하되, 접근성에 필요한 사용자 확대까지 일괄 차단하는 방식은 피한다.

## 5. 시간표의 이동 시간과 지도 경로 동기화

현재 불편:

- 시간표 탭에서 도보 또는 버스·지하철을 선택해도 지도에 경로가 즉시 나타나지 않는다.
- 로딩이 생기거나 시간표 탭에 갔다가 지도 탭으로 돌아와야 경로가 보인다.
- 다른 수업을 선택하면 출발지/현재 위치 상태가 초기화된다.
- 다시 지도 탭에서 길찾기를 해야 출발 필요 시간이 표시된다.

다음 패치 요구:

- 이동 방법 선택 결과와 지도 경로, 이동 시간, 출발 필요 시간을 같은 상태로 동기화한다.
- 탭을 왕복하거나 길찾기 버튼을 다시 누르지 않아도 선택한 경로가 표시되도록 한다.
- 다른 수업을 선택할 때 **기존에 선택한 출발지를 유지**하고 새 수업 장소까지 바로 계산한다.
- 현재 위치를 출발지로 쓰고 있었다면 그 출발지 선택 상태가 임의로 초기화되지 않게 한다.
- 필요한 조회 중에는 진행 상태를 명확히 표시하며, 이전 수업의 경로·시간이 새 수업 결과처럼 남지 않도록 한다.
- 지도·시간표가 같은 출발지와 같은 경로 조회 결과를 사용하도록 한다. 탭 전환만으로 이미 조회한 경로를 불필요하게 다시 조회하지 않는다.
- 외부 길찾기 서버 응답이나 GPS 최초 확인 시간을 0으로 보장할 수는 없다. 선택 즉시 조회·화면 갱신을 시작하고, 응답이 오면 탭 재방문 없이 자동 표시하는 것을 완료 기준으로 한다.
- 수업·출발지·이동 방법을 빠르게 바꿨을 때 늦게 도착한 이전 응답이 현재 선택을 덮어쓰지 않도록 한다.

## 6. 시간표 안에서 출발지 선택

- 시간표 탭의 도보/버스·지하철 선택 영역에 간단한 출발지 선택 기능을 둔다.
- **현재 위치로 설정** 버튼을 함께 제공한다.
- 시간표 탭에서 출발지를 설정하면 이동 시간과 출발 필요 시간을 바로 조회한다.
- 지도 탭으로 이동해 별도로 길찾기를 실행해야만 시간이 표시되는 흐름을 없앤다.
- 이 출발지 선택은 지도 탭과 공유하고, 다른 수업 선택 시에도 유지한다.
- 현재 위치 권한이 거부되거나 위치 확인이 실패하면 직접 검색으로 전환할 수 있게 한다. 유효한 기존 출발지가 있으면 새 위치 확인 실패만으로 지우지 않는다.

## 7. 학교 탭 진입 시 지도 이동·확대 및 범주별 마커

- **학교 내부 / 학교 주변** 탭에 진입하면 경북대학교 대구캠퍼스가 잘 보이는 위치와 배율로 지도를 이동한다.
- 학교 내부는 캠퍼스 중심, 학교 주변은 주변 상권을 함께 볼 수 있는 범위로 각각 맞춘다.
- 하단 패널에 학교가 가려지지 않도록 실제 노출된 지도 공간을 기준으로 중심·여백을 맞춘다.
- 전체/학식당/식당/카페/편의점 등을 선택하면 **목록과 지도 마커를 동시에 같은 범주로 필터링**한다.
- 전체는 현재 학교 탭·검색 영역에 해당하는 전체 범주를 뜻한다. 교내 결과와 교외 결과를 임의로 섞지 않는다.
- 이전 탭이나 이전 검색 결과의 시설 마커는 정리한다. 출발지·도착지·현재 위치·선택 경로 표시는 시설 필터와 별도로 유지한다.
- 조정안: 학교 위치로 자동 이동하는 것은 해당 학교 탭 진입 시에 적용한다. 같은 탭에서 범주 변경·재검색·패널 드래그를 할 때는 사용자가 옮겨 둔 지도 위치와 배율을 유지한다. 필요하면 별도 학교로 돌아가기 버튼을 제공한다.

## 7-1. 학교 내부·주변 하단 패널을 아래로 내려 접기

- 두 학교 탭의 하단 패널 상단에 **회색의 길쭉한 손잡이 바**를 넣는다.
- 손잡이를 실제로 드래그하면 패널이 아래로 이동해 일부가 화면 아래에 들어가고, 지도 노출 영역이 넓어진다.
- 패널 내용 자체를 축소하거나 글자 크기를 줄이는 동작이 아니다.
- 기본 절반 높이와 아래로 접힌 상태를 제공하며, 위로 끌어 기본 높이로 복원할 수 있게 한다.
- 접힌 상태에서도 손잡이·최소한의 제목은 남기고 하단 5개 메뉴는 계속 사용할 수 있게 한다.
- 손잡이 드래그와 패널 안 목록 스크롤을 구분해 시설 목록을 읽다가 패널이 의도치 않게 움직이지 않도록 한다.
- 마우스·터치 모두 지원하고, 드래그 없이도 접기/펼치기가 가능하도록 한다.
- 패널을 접거나 펼쳤다는 이유만으로 지도가 학교 중심으로 다시 이동하거나 시설을 다시 검색하지 않는다.

## 8. 현재 지도 영역에서 학교 주변 시설 재검색

- 학교 주변의 식당·카페·편의점을 고정된 학교 중심 반경만으로 검색하지 않고, **현재 화면에 보이는 지도 영역**을 대상으로 다시 조회할 수 있게 한다.
- 지도를 이동하거나 확대·축소한 뒤 **이 지도에서 재검색** 버튼을 제공한다.
- 버튼을 누르면 현재 범주를 유지한 채 해당 영역의 시설 목록·마커를 함께 갱신한다. 전체 범주이면 식당·카페·편의점을 함께 조회한다.
- 재검색으로 지도를 학교 위치로 되돌리거나 결과에 맞춰 자동 확대·축소하지 않는다.
- 하단 패널·상단 검색창에 가려진 부분은 사용자가 실제 보는 영역과 구분하여 검색 범위를 정한다.
- 사용자가 지도를 움직이는 동안 매번 자동 조회하지 않고, 명시적으로 재검색을 눌렀을 때 조회한다.
- 조회 중·결과 없음·일부 조회 실패를 구분하고, 중복 장소 제거·페이지 처리·이전 조회 응답 무시를 적용한다.
- 카카오 검색에서 제공하는 결과만 표시한다. 넓은 영역의 모든 가게를 빠짐없이 조회한다고 보장하지 않으며, 필요하면 더 확대해 검색하도록 안내한다.

## 9. 페이스메이커 복원 및 영상 플레이어 형태의 조작

- 사용자 보고: 어느 시점부터 페이스메이커 기능이 보이지 않는다. 기능이 제거된 것인지, 탭·패널 개편으로 진입점이나 표시 영역이 가려진 것인지 확인하고 다시 사용할 수 있게 복원한다.
- 도보 경로를 선택한 뒤 페이스메이커와 경로 미리보기에 쉽게 진입할 수 있게 한다. 지도나 다른 조작부에 가려지지 않게 한다.
- **미리보기, 재생/일시정지, 정지, 초기화** 조작을 제공한다.
- **미리보기 재생 배속 설정**을 제공한다. 이는 화면 속 시뮬레이션이 진행되는 배율이다.
- **목표 보행 속도 설정**을 별도로 제공한다. 이는 페이스메이커의 기준 보행 속도이며, 재생 배속과 구분하여 표시한다.
- 영상 재생 바처럼 전체 경로의 진행 상태를 나타내는 **진행 바와 드래그 가능한 손잡이**를 제공한다.
- 진행 바를 클릭하거나 손잡이를 앞뒤로 드래그하면 해당 경로 지점으로 즉시 이동해 여러 구간을 살펴볼 수 있게 한다. 실제 조작이 가능해야 하며 장식용 바로 끝내지 않는다.
- 이동한 지점에 맞춰 미리보기 마커, 진행률, 경과·남은 시간, 남은 거리를 함께 갱신한다.
- 일시정지는 현재 진행 위치를 유지하고, 재생하면 해당 위치부터 이어간다. 정지는 실행을 종료하고 현재 위치 확인은 유지하며, 초기화는 시작점·진행률 0으로 되돌린다.
- 경로를 바꾸면 이전 경로의 진행 상태를 정리하고 새 경로의 시작 상태로 전환한다.
- 미리보기에서 진행 바를 움직이는 동작은 실제 GPS 위치나 실제 이동 기록을 변경하지 않는다. 실제 위치 안내와 미리보기 모드를 명확히 구분한다.
- 휴대폰 터치와 마우스 모두로 진행 바를 조작할 수 있게 하고, 좁은 화면에서도 버튼과 설정이 잘리거나 지도를 과도하게 가리지 않도록 한다.

패치 전 코드 확인: 지도는 `src/map-service.js`, 학교 시설과 필터는 `src/campus-explorer.js`, 시간표 그리드는 `app/ui/week-calendar.js`에 있다. 현재 지도 어댑터에는 학교 중심 이동과 고정 반경 검색이 있지만, 실제 노출 영역 검색·패널 드래그·시설 필터와 마커 동기화는 추가 작업이 필요하다. 시간표와 지도는 같은 출처의 iframe 메시지로 연결되어 있어 5·6번은 양쪽 상태와 지도 표시 시점을 함께 보완해야 한다.

공식 기능 확인: [카카오 지도 Web API 문서](https://apis.map.kakao.com/web/documentation/#services_Places_categorySearch)의 지도 영역 조회·이동, 카테고리 검색의 `bounds`/`useMapBounds`, 페이지 처리 기능을 활용할 수 있다. 패널에 가려지지 않은 실제 노출 영역 계산과 결과 완전성 처리는 앱에서 별도로 구현한다.
