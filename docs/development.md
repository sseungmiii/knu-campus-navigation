# 다음 개발을 위한 안내

## 파일별 작업 위치

- 화면 구성: index.html
- 색상·카드·마커 스타일: src/styles.css, src/tailwind-config.js
- 건물·지름길·경계·식당 예시: src/campus-data.js
- 지도·출발시간·POI 모달·페이스메이커: src/app.js
- 경로 보간: src/route-utils.js

## 개발 후보

1. 경로와 건물 좌표를 현장 검증하고 데이터 출처 기록
2. 출발지·도착지 선택을 데이터 구조로 확장
3. 공통 학식 JSON 연동 및 식단 미등록 상태 표시
4. 시간표 저장과 사용자 설정
5. 모바일 화면 및 키보드 접근성 개선

현재 출발시간은 고정 이동시간으로 계산하며, 메뉴·혼잡도는 예시다. 외부 CDN과 지도 타일을 사용하므로 완전한 오프라인 실행은 지원하지 않는다.

큰 프레임워크 전환은 기능 요구가 생겼을 때 결정한다. 현재는 의존성 설치 없이 Node.js 기본 모듈로 개발 서버와 검증 명령을 실행할 수 있다.
