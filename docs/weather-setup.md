# 경북대 날씨와 수업 이동 예보

`KMA_API_KEY`를 Git 제외 파일 `.env.local`과 Vercel Production의 Secret 환경변수로 등록한다. URL 인코딩 키와 원문 키를 모두 지원하며 한 번만 디코딩한 뒤 서버에서 쿼리 인코딩한다. 브라우저·지도 자산·응답·로그에는 키나 인증 URL을 넣지 않는다. 환경변수 변경 후 배포해야 적용된다.

`GET /api/weather`는 경북대학교 대구캠퍼스의 기상청 격자(89,91)만 조회한다. 사용자 GPS·수업 정보는 날씨 제공기관에 보내지 않는다. `getUltraSrtNcst`의 관측값, `getUltraSrtFcst`의 가까운 시간 예보, `getVilageFcst`의 기온·강수확률을 함께 사용한다. 기온, 습도, 풍속, 강수량은 관측 시각을 표시하며 하늘 상태는 예보 화면에서만 표시한다. 현재 강수가 없다는 사실을 현재 맑음으로 바꾸지 않는다.

한국 시각 기준 발표 주기를 계산하며 자정·발표 직후를 처리한다. 자료가 없으면 이전 발표를 한 번 조회한다. 초단기 예보의 기온·강수형태를 우선하되 단기 예보의 강수확률은 유지한다. 연장 예보기간의 3시간 구간도 구별한다. 제공 범위를 넘어선 수업·중간에 빠진 예보는 예보 없음으로 표시한다.

서버 인스턴스에서 10분 캐시와 동시 요청 병합을 사용한다. 외부 장애 시 1시간 이내 캐시만 자료 지연 표시와 함께 제공한다. 실패 후 1분은 재시도를 제한한다. 관측·예보 모두 없는 경우 오류를 반환하며 임의의 맑음·0%를 표시하지 않는다. 요청별 시간 제한과 기존 API의 출처 검사·호출 제한을 유지한다.

지도 오른쪽 아래 카드에는 관측 기온·현재 강수·습도가 보이며 누르면 다음 6개 시간대의 예보가 나온다. 지도 메뉴·시설 카드를 열면 날씨 카드를 숨겨 조작을 가리지 않는다. 숨겨도 자료 갱신은 계속한다. 수업 선택 화면에는 경로의 예상 출발부터 수업 시작까지의 기온 범위와 최대 강수확률, 비·눈 안내를 표시한다. 경로를 찾기 전에는 수업 시간대 기준이다. 우산 안내의 40% 기준은 앱의 안내 기준이며 기상청 공식 특보 기준이 아니다.

검증: 공식 API 실조회, 한국 시각 날짜 전환, 예보 합치기와 미제공 자료, 비·눈 및 예보 공백, 키 인코딩, 키 비노출, 동시 요청·캐시·실패 시 지연 표시, 전체 테스트와 빌드.
