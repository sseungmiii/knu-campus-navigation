# 시간표 중심 캠퍼스 길찾기 개발 계획

목표는 수업을 누르면 현 위치에서 언제 출발하고, 어디서 무엇을 타고, 어느 출입구로 들어가야 하는지 보여주는 것이다. 강의실 도착을 기준으로 계산한다.

| 기능 | 현재 | 필요한 다음 작업 |
|---|---|---|
| 회원가입·시간표 | 아이디·비밀번호 즉시 가입, Supabase 저장, 본인 데이터 접근 제한 | 이메일 없이 가입·로그인 전체 흐름 확인 |
| 수업 길찾기 | 수업 장소·시작 시각 전달, 출발지가 있으면 경로 조회 | 클릭 시 GPS 요청, 위치 최신성 확인, 도착 기준 출발 마감 계산 |
| 교통 안내 | 예상 시간·여유 시간, 일부 정류장 실시간 버스 정보 | 도보/교통 후보 비교, 탑승·환승·데이터 갱신 시각 표시 |
| 교내 시설 | 일부 식당·카페·편의점 표시 | 건물 ID·별칭·출입구·층·호실·운영 시간 조사 |
| 지름길·실내 | 검증된 연결망 미구축 | 실제 경로선·계단·경사·통행 시간·폐쇄 상태 조사 후 경로 탐색 통합 |
| 에브리타임 | 연동 미구현 | 공식 API와 사용 허가 확인. 우선 이미지 인식 후 사용자 확인 방식 검토 |

## 지금 구현할 수 있는 것

기존 시간표와 경로를 연결해 수업 시각에서 예상 이동 시간, 실내 이동 시간, 여유 시간을 뺀 출발 마감을 계산할 수 있다. 위치 실패·오래된 위치·경로 미제공을 별도로 안내한다. 대중교통은 배차와 환승 대기를 포함해야 하므로 총시간 역산만으로 특정 차량 탑승을 보장하지 않는다.

수업에 건물·층·호실·개별 여유 시간을 추가하고 일회성 일정, 휴강·보강을 별도 관리할 수 있다. GPS는 목적을 알리고 길찾기에 필요한 동안만 사용하며 지속 저장할 필요는 없다.

## 확보해야 할 데이터

시설은 정식 명칭·별칭·건물 ID·실제 출입구 좌표·층·호실·운영 시간·확인일을 수집한다. 지도에 없는 시설은 건물 검색 결과에 시설명을 표시하고 실제 출입구에 핀을 연결한다. 건물 중심점을 출입구로 간주하지 않는다.

지름길은 연결점과 실제 보행선, 방향, 계단·경사, 통행 시간, 폐쇄 상태, 출처·확인일이 필요하다. 자주 쓰는 10개 경로부터 현장 확인한다. 공공 도로와 교내 그래프를 연결하고 임의 직선으로 잇지 않는다. 실내는 층별 평면과 출입 가능 정보를 확보한 건물부터 제공한다.

교통은 정류장·노선·방향을 일치시키고 갱신 시각을 확인한다. 지하철 시간표는 실시간 위치와 구별하며 공휴일·자정 이후 운행을 처리한다. 지연과 누락 시 추정임을 표시한다.

## 에브리타임과 Supabase

공식적으로 지원하는 공개 시간표 API 문서와 사용 조건은 아직 확인하지 못했다. 비공개 API 분석이나 에브리타임 비밀번호 수집은 구현하지 않는다. 공식 연동 전에는 수동 등록과 시간표 이미지 업로드 → 과목·시간·장소 추출 → 사용자 수정·확정 → 저장 순서가 현실적이다. 공유 URL도 지원 방식과 허용 범위를 확인한 뒤 판단한다.

사용자 수업·일정·환경설정은 소유자 RLS로 분리한다. 시설·출입구·지름길은 검수한 공개 데이터로 관리하고 편집은 관리자에게 제한한다. 이미지 가져오기를 추가하면 원본은 추출 후 기본 삭제하며 보관은 별도 동의를 받는다.

## 우선순위

1. 회원가입과 개인 시간표 운영 검증.
2. 수업 한 번 클릭 → 현 위치 → 출발 마감과 탑승 단계 안내.
3. 건물·강의실 데이터와 지름길 10개 검증.
4. 이미지 기반 시간표 가져오기와 확인 화면.
5. 교통 예측 개선과 출발 알림. 알림 권한과 브라우저 백그라운드 제약 확인 필요.

이번 변경은 회원가입과 가입 회원 개인 시간표 이용이다. 나머지는 이후 개발 범위다.
