# 대구 이동 기능

- 이동 수단에서 대중교통을 선택하면 카카오 REST API가 반환한 전체 후보를 비교합니다. 앞의 5개로 자르거나 서버에서 시간순으로 재배열하지 않으며, 원래 응답 순서를 보존합니다. 기본은 최소환승순이고 전체 / 버스 / 지하철 / 버스+지하철 필터와 추천순·최단시간순·최소도보순·최소환승순을 제공합니다. 추천순은 카카오 API 응답 순서이며 카카오맵 앱의 비공개 추천 알고리즘과 동일하다고 보장하지 않습니다. 최소도보순은 확인된 전체 도보 거리 기준이고, 도보 연결이 불완전한 후보는 뒤에 둡니다. 카드에는 전체 시간·환승·도보·요금·구간별 시간 막대·승하차 위치를 표시합니다. 버스는 종류별 색, 지하철은 호선별 색, 도보는 회색으로 카드와 지도를 일치시킵니다. 페이스메이커는 도보 경로에서만 사용합니다. [공식 API 문서](https://developers.kakao.com/docs/ko/kakaomap/rest-api#request-public-transportation-directions)
- 시간표의 수업을 선택하면 다음 해당 수업 날짜/시각을 지도에 전달합니다. 수동으로 수업 시작 시각을 설정할 수도 있습니다. 출발 마감은 경로 예상 시간 + 사용자가 설정한 내부 이동 시간 + 여유 시간으로 계산하며, 강의실까지 실내 경로를 제공한다는 의미는 아닙니다.
- `DAEGU_BUS_API_KEY`는 서버 환경변수입니다. 인코딩/디코딩 키 모두 지원하며 브라우저에 전달하지 않습니다. 로컬 `.env.local`에 등록되어 있습니다. Vercel Production에도 같은 이름으로 등록 후 재배포해야 합니다.
- 버스 승차 정류장은 공식 기초정보의 이름 및 경로 시작 좌표를 비교해 100m 이내, 인접 후보가 충분히 구분되는 경우에만 연결합니다. `data/daegu-bus-stops.json`은 2026-10-10 공식 기초정보에서 생성한 공개 정류장 스냅샷이며 키가 없습니다. 향후 노선 변경 시 갱신해야 합니다.
- 실시간 버스 도착 정보는 정류장별로 20초 캐시합니다. 사용자가 새로고침합니다. 해당 경로 노선만 표시하고, 도착 시간이 지난 버스는 목표 후보에서 제외합니다. 첫 버스 탑승 목표와 이후 예상 이동을 이용한 강의실 도착을 표시합니다. 이후 환승은 예상값이며 1분이 지난 조회는 마감 계산에 사용하지 않습니다.
- 지하철은 공식 stationTime.php XML을 사용합니다. 2026-10-16 수정: 공개 API의 접속 확인 쿠키를 같은 호스트에 1회 재전송하고 외부 JavaScript는 실행하지 않습니다. 동대구역·대구역은 공식 역명에 역을 포함하므로 별도로 정규화합니다. 오래된 연결 재사용 오류를 막고 성공 결과를 5분 캐시합니다. 응답의 역·호선·방향을 검증하며 종착역 표기도 보존합니다. 공식 운행 시간표이며 실시간 도착이 아닙니다. 공휴일과 방향은 사용자가 선택합니다. 자정 이후에는 운행일 경계에 유의해야 합니다.
- 시설 검색은 도보 경로의 시작/중간/끝 주변 카카오 카테고리 검색 결과를 경로까지 350m 이내로 필터합니다. 전체 경로의 모든 시설을 보장하지 않으며 추가 소요 시간은 직선 왕복거리 추정입니다. 영업시간/영업 여부는 API에 없어서 단정하지 않습니다. 대중교통 이용 시 도보 구간만 검색합니다.
- 학식은 기존 공개 `knu_meal_test/main/menu.json`을 서버에서 5분 캐시합니다. 오늘 날짜만 표시하고 식단 없는 식당도 유지하되 아래로 정렬합니다. 학식은 캠퍼스 전체 목록이며 아직 시설 경로 필터와 자동 위치 매칭하지 않습니다.
- 실내 지도는 실제 층별 도면과 출입구·계단·엘리베이터 자료가 필요한 후속 작업입니다. 현재 내부 이동 시간은 사용자가 입력하는 예상값입니다.

공식 문서: https://developers.kakao.com/docs/ko/kakaomap/rest-api / https://www.data.go.kr/data/15139134/openapi.do / https://www.dtro.or.kr/open_content_new/ko/OpenApi/stationTime.php

- 화면은 길찾기 / 지하철 / 주변 시설 / 학식 탭으로 구분합니다. 수업 출발 계산은 펼침 메뉴이며 시간표에서 강의를 선택하면 자동으로 길찾기로 돌아와 펼칩니다. 키보드 방향키로 탭을 바꿀 수 있습니다.
- 지하철은 역 이름 입력 후 조회하면 1~3호선의 공식 시간표에서 해당 역의 호선을 자동 확인합니다. 환승역은 조회된 호선을 변경할 수 있습니다. 양방향을 종착역 방면으로 나눠 다음 세 열차의 남은 시간을 매초 계산하며 지난 열차는 제외합니다. 제공된 초 정보도 보존합니다. 03시 전은 전날 운행일로 취급하여 24시 표기 열차를 연결하며, 운행일이 바뀌면 재조회를 안내합니다.
- 운행일은 서버의 한국 시간과 `date-holidays` 한국 공휴일 달력을 기준으로 자동 선택하며 수동 변경도 가능합니다. `server/metro-calendar.cjs`는 3.37.0의 설날 연휴 시작일을 보정하고 2026년 노동절 공휴일 지정과 지방선거일을 보완합니다. 새 임시공휴일·선거일·법정 변경은 달력 갱신이 필요합니다. 근거: [인사혁신처 공휴일 보도자료](https://www.mpm.go.kr/mpm/comm/newsPress/newsPressRelease/?mode=list&searchCondition=title&searchKeyword=%EA%B3%B5%ED%9C%B4%EC%9D%BC), [한국천문연구원 2026년 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?year=2026), [date-holidays 한국 규칙](https://github.com/commenthol/date-holidays/blob/master/data/countries/KR.yaml).
- 내 주변 역 찾기는 버튼을 누른 뒤 한 번 위치를 받아 카카오 `SW8` 카테고리로 직선 5km 이내 대구 1~3호선 역을 거리순으로 보여줍니다. 위치를 저장하지 않으며, 역 선택 시 해당 호선의 양방향 열차를 조회합니다. 위치 권한 거부·검색 실패·검색 결과 없음은 직접 역명 입력으로 이어집니다.
- 학식의 식당 위치 검색은 정보센터식당→종합정보센터, 복지관 교직원식당·카페테리아 첨성→복지관, GP감꽃식당→글로벌플라자, 공학관 교직원·학생식당→공대12호관의 경북대학교 건물명으로 검색합니다.
- 오늘의 학식은 메뉴를 열 때 자동 조회하며 전체 / 조식 / 중식 / 석식으로 구분합니다. 각 식당 카드에서 운영시간과 메뉴별 가격을 분리해 표시하고, 선택한 식사의 식단이 있는 식당부터 보여줍니다. 가격·운영시간 미제공과 식단 미등록을 휴무로 단정하지 않습니다. 브라우저에서도 당일 결과를 5분 재사용하며 수동 새로고침이 가능합니다. 날짜가 바뀌면 이전 날짜의 식단을 비웁니다. 교내 식당 핀과 건물 길찾기 연결은 유지합니다.
